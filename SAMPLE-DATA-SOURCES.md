# Sample source data

On server startup, Cheki Kiongozi adds these four **draft** project records to Super Data when they are not already present. They are drawn from Njoro Constituency NG-CDF Board-approved FY 2024/25 project proposals. They are not field-verified and do not claim that any work was completed. The proposal status is retained in each record's description.

| Source-listed project | Proposal amount (KSh) | Source location |
|---|---:|---|
| Bagaria Primary School — tree planting and water tank | 400,000 | PDF page 1, item 6 |
| Analat Primary School — two classrooms | 2,200,000 | PDF page 2, item 11 |
| Kusumek Primary School — classroom completion | 200,000 | PDF page 3, item 20 |
| Kenyatta Mixed Day Secondary School — administration block | 1,200,000 | PDF page 5, item 45 |

**Source:** [Njoro NG-CDF, “Njoro Financial Year 2024–2025”](https://njoro.ngcdf.go.ke/wp-content/uploads/2026/10/Njoro.pdf), listed on the [official constituency downloads page](https://njoro.ngcdf.go.ke/downloads/). The approved proposals list states the names, proposed activities, amounts and “New” or “Ongoing” status.

The records start as private drafts. An administrator must open the source, check that each source detail and page locator is accurate, and confirm the source's reuse terms before publishing. They do not create a People’s Grade, Evidence Grade or voter record. No project is described as ground-verified.
